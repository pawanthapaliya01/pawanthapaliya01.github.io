Hey there, thanks for stopping by! 👋

I am a computational scientist and physicist with a PhD in Applied Physics, specializing in quantitative modeling, scientific computing, data analysis, and machine learning. My research experience spans computational biophysics, neuroscience, medical imaging, and complex biological systems, where I develop mathematical and computational approaches to analyze data and understand complex dynamical processes.

My work combines mathematical modeling, numerical simulation, statistical analysis, and machine learning. I have developed differential-equation, Markov, Monte Carlo, and predictive models, and have applied these approaches to experimental and imaging datasets. I also have experience developing deep-learning pipelines using Python, PyTorch, TensorFlow, and scikit-learn, including applications to EEG, quantitative MRI, image analysis, and biomarker development.

During my PhD research, I focused on building mathematical models of neuronal excitability events to investigate complex dynamical processes in neuronal systems.

I enjoy working at the intersection of mathematics, computation, and real-world data—turning complex problems into quantitative models, building reproducible computational pipelines, and extracting meaningful insights from large and multidimensional datasets.

Outside of research, I enjoy running, reading, gaming, and spending time with friends and family. Want to dive deeper? Check out my projects or download my CV.

Projects

Project 1: SVM classifer applied on Heart-disease-dataset

Forward selection techniques were applied to the Kaggle Heart Disease dataset. Initially, the original dataset underwent feature selection using Sequential Feature Selector, which filtered features based on their performance in logistic regression classification. Subsequently, both the original features and the features selected through forward selection were utilized to train SVM classifiers. Notably, improved accuracy scores were obtained under the conditions of forward feature selection compared to the original datase

Skills Gained:

Data exploriing, wrangaling, preprocessing, mode traing and testing and deployment [PDF]

Project 2: Weather Prediction Using Machine Learning

Developed a machine learning workflow to predict temperature using weather observations from multiple European locations. Applied data preprocessing, Z-score normalization, Random Forest regression with hyperparameter tuning, and ARIMA time-series modeling. Evaluated model performance using RMSE and analyzed feature importance.

Skills Gained:

Python, Pandas, NumPy, Scikit-learn, Random Forest, GridSearchCV, Time-Series Analysis, ARIMA, Data Preprocessing, Feature Importance, Model Evaluation, Data Visualization. [PDF]

Project 3: BCCD Dataset – U-Net Cell Segmentation

Developed a U-Net deep learning model to segment blood cells from microscopic images using the BCCD dataset. The project includes image preprocessing, mask generation, model training, validation, and segmentation prediction.

Skills Gained:

Image preprocessing, data augmentation, deep learning, U-Net architecture, image segmentation, model training/testing, performance evaluation, and visualization. [PDF]

Project 4: Machine Learning-Based Benign and Malignant Classification
